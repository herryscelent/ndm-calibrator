# 用户指南 — NDM-Calibrator V1.0

## 快速开始

1. 启动软件: `python -m app.main` 或双击 `run.bat`;
2. **文件 → 新建项目** (Ctrl+N);
3. **数据管理** → **导入 CSV / XLSX**, 选择 `examples\first_order\data.csv`;
4. 软件自动映射 `time` / `u` / `x` 为 时间 / 输入 / 输出;
5. **模型定义** → 选择"一阶惯性系统" → **验证模型** (显示 "模型有效");
6. **参数配置** → 设置 K、τ 的初值与边界;
7. **参数辨识** → 选择算法 → **开始辨识**;
8. **模型校准** 查看拟合曲线与指标;
9. **诊断分析** 查看残差、敏感度、可辨识性;
10. **可信度分析** 运行 Bootstrap;
11. **结果导出** 导出 Excel / HTML 报告;
12. **文件 → 保存项目** (Ctrl+S) 保存为 `.ndmc`, 可随时重开。

## 界面说明

### 顶部栏

- 软件名称、当前项目名、未保存标记;
- 打开 / 保存按钮;
- 主题切换 (浅色/深色)。

### 左侧导航

- 工作流: 项目首页 → 数据管理 → 模型定义 → 参数配置 → 参数辨识 → 模型校准 → 诊断分析 → 可信度分析 → 结果导出;
- 应用: 设置 → 关于;
- 可折叠 (点击导航区底部的折叠按钮, 状态自动保存)。

### 状态栏

底部显示当前状态: Ready / Loading / Running / Completed / Error。

## 数据导入与映射

支持 CSV (UTF-8/GBK 自动识别) 与 XLSX。
导入后自动将常见时间列识别为时间, 最后一列数值列为输出, 其余为输入。
数据质量检查自动运行, 异常 (时间回退/重复时间戳/NaN) 以警告列出, 不会崩溃。

## 模型定义

### 内置模型模板

| 模型 | 说明 |
| --- | --- |
| 指数衰减 | dx/dt = -k·x |
| 一阶惯性系统 | dx/dt = (-x + K·u)/τ |
| 二阶质量-弹簧-阻尼 | dx1/dt=x2; dx2/dt=(-k·x1 - c·x2 + u)/m |
| Logistic 动态模型 | dx/dt = r·x·(1-x/K) |
| 非线性动态模型 | dx/dt = -a·x - b·x³ + c·u |

### 自定义模型

在"用户自定义模型"标签页输入状态/输入/参数/方程, 点击**验证模型**。
格式见 [MODEL_FORMAT.md](MODEL_FORMAT.md)。

## 参数配置

表格中可编辑每个参数的:

- 初值 (Initial);
- 下限 (Lower);
- 上限 (Upper);
- 状态: 待辨识 (Free) / 固定 (Fixed)。

要求 `lower < initial < upper`, 违反时页面即时提示。

## 参数辨识

选择算法:

- **非线性最小二乘** — 局部, 快速;
- **Nelder-Mead** — 无梯度局部;
- **Differential Evolution** — 全局搜索, 适合非线性/多局部极小;
- **Multi-start** — 多起点局部, 提供稳定性分析基础。

运行在后台线程, GUI 不冻结; 可随时**取消**。
辨识完成后自动进入校准页并展示拟合结果。

## 校准与诊断

- 校准页: RMSE / MAE / R² / 用时 + 实测 vs 模拟曲线 + 误差时序;
- 诊断页 (标签页): 残差统计与 ACF、敏感度条形图、可辨识性 (条件数/秩/奇异值/警告)、参数相关热力图。

所有图表支持缩放/平移/导出 PNG。

## 可信度分析

- **多起点稳定性**: 成功率、最优目标值、各参数分布与变异系数;
- **Bootstrap**: 设置 B (默认 100) / seed / 算法, 运行后得到每个参数的
  **Bootstrap percentile interval** (2.5%–97.5%), 并绘制分布直方图。

## 结果导出

- **Excel**: 一个 `.xlsx` 包含项目信息/参数/指标/模拟/残差/可辨识性/Bootstrap;
- **HTML 报告**: 白底出版风格, 内嵌拟合与残差图;
- **图片 / CSV**: 另支持独立导出 (见导出模块)。
